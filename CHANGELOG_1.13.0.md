# MOHSEN SCOUT 1.13.0

## First implementation slice

- Add an Android in-app web browser reachable from Deep Research.
- Restrict browser navigation to HTTP and HTTPS; reject credential-bearing URLs and non-web schemes.
- Disable file access, mixed content, automatic JavaScript windows and shared/third-party cookies in the embedded browser.
- Bump Android version to 1.13.0 (versionCode 32).
- Run the signed ARM64 APK workflow on the dedicated 1.13.0 release branch and publish only after signature, package identity, ABI and checksum verification.

This is an incremental release slice. YouTube-derived ranking and growth metrics remain unchanged until the applicable project policy is explicitly authorized and verified.
