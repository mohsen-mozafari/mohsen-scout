# MOHSEN SCOUT 1.14.0

## YouTube discovery foundation

- Add a three-lane official YouTube Data API Discovery Mix: YouTube view-count order, newest-first order, and relevance order.
- Interleave unique results from the three lanes while preserving each lane's returned order.
- Add independent page cursors for each lane so pagination continues without restarting completed lanes.
- Keep video and channel statistics as raw, temporary YouTube metadata; do not calculate growth, velocity, ratios, market rankings, or composite opportunity scores.
- Add direct paths from YouTube research to independent web/news research and the in-app browser.
- Keep independent web/news research and YouTube API data in separate evidence lanes.
- Bump Android version to 1.14.0 (versionCode 33).

## Policy boundary

Custom derived metrics from YouTube API data remain disabled unless YouTube has formally approved the applicable audited analytics use case and permissions. User consent alone does not grant that approval.
