# MOHSEN SCOUT v1.23.0 — Unified UI/UX Refresh

## Interface and visual system
- Refresh the dark visual language with layered navy surfaces, clearer borders and more legible typography while preserving the existing blue identity and semantic status colors.
- Show page and section subtitles that were previously accepted by shared UI components but not rendered.
- Improve touch targets, tab labels, fold headers, form fields and information hierarchy across shared screens.
- Avoid duplicate page-level and in-page hero titles in Discover.

## Research continuity and archive
- Open the exact latest saved YouTube report from Discover using its persisted report ID instead of reopening an empty research form.
- Add a unified Workspace archive for saved YouTube reports and complete Deep Research briefs stored in Notes.
- Tag newly saved Deep Research briefs so the archive can locate them without changing the Notes storage model.
- Show the internal engine findings and iterative dossier by default after a Deep Research run while keeping secondary evidence sections collapsible.
- Preserve all existing YouTube, publisher, web, Wikimedia, idea-generation, review, browser, activity, diagnostics, settings, backup and notes features.

## Localization and correctness
- Extend Persian UI translations across Deep Research, YouTube sampling, browser, note editor, diagnostics and archive copy without translating original source titles.
- Correct the research activity time-range anchor so it is based on the current time when filters are recalculated.
- Add navigation and Persian localization regression checks.
- Release as version 1.23.0 / Android versionCode 44.
